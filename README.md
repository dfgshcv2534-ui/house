# 🏠 수도권 공공주택 모아보기

서울·경기·인천의 **분양**(공공·민영 아파트, 무순위·잔여세대, 오피스텔) 공고와 **임대**(SH·GH·iH·LH 행복주택, 국민임대, 장기전세·미리내집, 매입임대 등) 공고를 매일 오전·오후 6시에 모아서 D-day 순으로 보여주는 사이트입니다.

## 화면 구성

- **지역 선택**: 서울(기본) · 경기 · 인천 · 수도권 전체. 시·군·구 필터는 고른 지역에 맞춰 바뀌어요.
- **분양 / 임대 / 특수형 / 전체** 탭. 분양이 첫 화면이에요.
  - **특수형**: 토지임대부 분양, 분양전환 임대(5·10년 공공임대 등), 지분적립형, 나눔형(이익공유)처럼 소유 구조나 전환 조건이 다른 주택. 카드와 상세 화면에 유형별 특징을 보여줘요. 토지임대부 *사회주택*은 임대예요.
- **공공 / 민간** 토글: LH·SH·공공분양(국민주택)은 공공, 민영 아파트·오피스텔·공공지원민간임대 등은 민간
- 요약 카드: 접수중 · 7일 안에 마감 · 접수 예정 · 새 공고. 누르면 그 조건으로 필터돼요.
- 필터: 검색, 유형, 자치구, 정렬(마감 임박순 / 최신순 / 분양가 낮은순), 상태, 대상(청년·신혼 등), ☆ 관심
- 카드: 상태와 D-day, 유형, 분양가 범위와 평당가, 접수·발표 일정, 공급 세대, 입주 시기
- 상세 화면: 일정 타임라인(특공 → 1순위 → 2순위 → 발표 → 계약 → 입주), 주택형별 분양가 표, 공고 원문 링크, **캘린더에 추가(.ics)**, **링크 공유**
- 주택형 표에서 📐 표시가 있는 타입을 누르면 **평면도**를 보여줘요
  - LH: 공고의 평면도 이미지 / SH: 평면도 첨부파일
  - 청약홈(민간): **분양 홈페이지**를 실제 브라우저로 열어 세대안내·평면안내 페이지의 평면도 이미지를 찾아 타입과 짝지음 (원본 이미지 표시, 주 1회 재확인)
  - 청약홈: 모집공고문 PDF에 평면도 페이지가 있으면 이미지로 잘라 '공고문 속 평면도'로
  - 그래도 없으면 PDF·분양 홈페이지·네이버 부동산 버튼으로 안내
- **위치 지도**: OpenStreetMap 지도에 대략적인 위치(주소 → 동 → 자치구 중심 순으로 찾음)와 카카오맵·네이버지도 링크
- **일정표** 보기: 앞으로 90일 동안의 접수 시작·마감·발표를 날짜별로 정리
- 관심 공고(☆)는 각자 브라우저에만 저장돼요.

## 데이터 출처

| 출처 | 방식 | 내용 |
|---|---|---|
| 청약홈 (한국부동산원) | 공공데이터포털 API | 수도권 APT·무순위·임의공급·오피스텔/도시형·공공지원민간임대, 주택형별 분양가 |
| SH 서울주택도시공사 | 공개 게시판(i-sh.co.kr) 읽기 | 주택분양·주택임대·주택매입 게시판의 모집공고. 일정은 본문에서 자동 추출 |
| GH 경기주택도시공사 | 공개 목록(apply.gh.or.kr) 읽기 | 임대주택·매입임대 공고. 목록의 유형·시군·공고일·마감일·상태 사용 |
| iH 인천도시공사 | 공개 게시판(ih.co.kr) 읽기 | 주택분양·임대 입주자모집공고. 일정·주소는 본문에서 자동 추출 |
| LH | 공공데이터포털 API (선택) | 수도권(서울·경기·인천) 분양·임대 공고. 상세정보 서비스로 주소·일정·입주 예정·단지 이미지, 공급정보 서비스로 주택형별 세대수 |
| LH 사전청약 | 공공데이터포털 API (선택) | `collector/lh.py`의 `PRE_LIST_URL`·`PRE_DTL_URL`에 요청주소를 넣으면 켜져요 |

- 한 출처가 실패해도 나머지는 업데이트되고, 실패한 출처는 전날 데이터를 유지해요. 이때 화면 위쪽에 안내가 표시돼요.
- 청약홈과 SH·LH에 같은 분양 단지가 있으면 청약홈 항목 하나로 합쳐요.
- SH 일정은 공고 본문 글에서 자동으로 읽은 값이라 틀릴 수 있어요. 본문에 일정이 없으면 '일정 확인'으로 표시돼요.

## 처음 설정 (한 번만)

1. **공공데이터포털 활용신청** ([data.go.kr](https://www.data.go.kr))
   - `한국부동산원_청약홈 분양정보 조회 서비스` (필수)
   - `한국토지주택공사_분양임대공고문 조회 서비스` (선택. 신청하지 않으면 LH만 건너뛰어요)
   - `한국토지주택공사_분양임대공고별 상세정보 조회 서비스` (선택. LH 공고의 일정·주소·이미지)
   - `한국토지주택공사_분양임대공고별 공급정보 조회 서비스` (선택. LH 주택형별 세대수)
   - `…(사전청약)` 두 서비스 (선택. 요청주소를 `collector/lh.py`에 넣어야 켜져요)
   - 모든 서비스가 같은 서비스키를 써요. 서비스를 추가로 신청해도 Secret은 그대로 두면 돼요.
2. **서비스키를 Secret으로 등록**: 레포 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `DATA_GO_KR_KEY`
   - Secret: 마이페이지의 **일반 인증키(Decoding)**. Encoding 키를 넣어도 동작해요.
   - ⚠️ 키를 코드, 이슈, 채팅에 붙여넣지 마세요.
3. **GitHub Pages 켜기**: **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`, 폴더: `/docs` → Save
4. **첫 수집 실행**: **Actions → 매일 공고 업데이트 → Run workflow**
5. 몇 분 뒤 `https://<사용자명>.github.io/house/` 에서 확인하세요.

이후에는 매일 06:00·18:00(KST)에 자동으로 실행돼요. GitHub 사정으로 조금 늦어질 수 있어요.

## 로컬에서 돌려보기

```bash
pip install -r requirements.txt pytest
python -m pytest -q
DATA_GO_KR_KEY=발급받은키 python -m collector      # docs/data/*.json 갱신
python -m http.server -d docs 8000                   # http://localhost:8000
```

  pdfplans.py    청약홈 모집공고문 PDF에서 평면도 페이지 골라 docs/plans/에 이미지로 저장
